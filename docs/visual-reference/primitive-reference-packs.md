# Primitive Visual Reference Packs

## Purpose

Each primitive has a canonical reference pack to anchor redraw work in real equipment geometry.
Each pack is a capture checklist, not a topology definition.

## Required capture fields per primitive

- Installer brochure references.
- Silhouette studies.
- Simplified geometry breakdown.
- Connection position study.
- Real-world installation photo references.
- Minimum recognisable shape notes.

## Primitive packs

### 1. Boiler (wall-mounted, combi/system/regular family)

- Installer brochure references:
  - Vaillant ecoTEC installation manual (front silhouette and underside connections).
  - Worcester Bosch Greenstar installation guide (underside service spacing).
- Silhouette studies:
  - Tall vertical appliance body, softened corners, lower fascia break.
- Simplified geometry breakdown:
  - Body block, control fascia strip, underside connection rail.
- Connection position study:
  - Bottom-only ports, left-to-right service order variants by boiler type.
- Real-world installation photo references:
  - Utility cupboard and kitchen wall-mount installs with visible service tails.
- Minimum recognisable shape:
  - Appliance rectangle + underside 3/5-port rhythm + fascia break.

### 2. Unvented cylinder

- Connection position study:
  - Top draw-off, bottom cold in, lower-third coil flow/return.
- Real-world installation photo references:

- Minimum recognisable shape:

## Pack completion status

All packs are currently defined as capture templates for screenshot curation.
A primitive cannot enter redraw approval until all six capture fields above are populated with reviewed evidence.
